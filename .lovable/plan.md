# Responsive Gallery Polish

## Changes
- Improve spacing, sizing, and gallery controls for comfortable mobile and laptop use.
- Keep the category filters hidden initially and add one Categories button to open or close them.
- Turn the search field border into a continuously moving RGB light effect, with reduced-motion support.
- Rename “Uploader Name” to “PHOTO NAME” in English and update its placeholder to describe a photo title.
- Preserve existing upload, filtering, rating, download, theme, and language behavior.

- Add a small local visibility state for the category panel.
- Use existing semantic styles plus a CSS keyframe utility for the RGB search border.
- Adjust responsive grid, toolbar, card controls, and full-screen viewer sizing.
- Verify the page at mobile and laptop widths after implementation.
